02 Position

Frontend, pointed at problems that bite back.

Most frontend work is judged on how it looks. Mine is judged on whether a security administrator can trust what the screen is telling them at two in the morning. That changes the priorities: state modelling over styling, honesty over polish, and a visible admission of staleness rather than a confident lie.

The second half of my work points inward. I build the tooling and component systems other engineers depend on — most recently, developer surfaces for spec-driven delivery with AI agents. Engineers are the least forgiving users there are, which makes them the most useful ones to design for.

03 Selected work

Now Senior Software Engineer II

Genea — cloud-native access control

The operator dashboard for a platform that controls physical doors across commercial real estate. Doors change state from hardware, from other operators, and from schedules, all at once. I treat the interface as a projection of an event stream rather than a cache of responses — one authoritative reducer, explicit reconciliation, and a staleness indicator instead of a silent lie.
